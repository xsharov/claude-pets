# Claude Pets

[English](README.md) · **Русский**

Аналог системы Pets/Mini из Codex теперь доступен в Claude Code desktop на Windows и macOS.
Он полностью дублирует функционал оригинала, но работает экстремально быстрее за счет реализации на C++.

Все питомцы используют формат Codex pets v2, поэтому подходят готовые из `~/.codex/pets`.

![Питомец показывает ошибку сессии в бабле](docs/pet-status.gif)

## Что умеет

- Показывает в баблах сессий Claude desktop статус треда.
- Открывает сессию в Claude по клику на бабл.
- Меняет анимацию питомца: работа, ожидание, ошибка, готово.
- Перетаскивается мышью. Если отпустить питомца с зажатым Alt (Option на macOS), он прилипнет к углу или середине края экрана.
- Поворачивает голову к курсору, если у питомца есть кадры взгляда.
- Разворачивает стопку баблов при наведении и прячет её в счётчик по кнопке.
- Прячется в трей (в строку меню на macOS) по `Ctrl+Alt+P` (`⌃⌥P` на macOS).
- Подстраивается под светлую или тёмную тему системы.

## Почему он лёгкий

- Написан на C++20, без Electron, браузера и .NET.
- Windows: Win32 API и Direct2D. Весь питомец — один exe примерно на 750 КБ, Visual C++ Redistributable не нужен.
- macOS: AppKit и Core Animation. Приложение весит около 1 МБ; баблы и питомец — слои, которые складывает видеокарта, поэтому кадр стоит около 0,2 мс процессорного времени.
- Занимает 20–30 МБ памяти.
- Перерисовывает только то, что изменилось: кадр питомца, кнопку или мерцающую строку, а не всё окно.
- Поддерживает разные герцовки монитора.
- Хуки Claude Code запускаются асинхронно и без оболочки, поэтому Claude их не ждёт.
- Проверен на утечки.

## Установка

Нужен Claude desktop с сессиями во вкладке **Code**.

### Windows

Нужны Windows 10 или 11 x64.

1. Скачать `claude-pets-<версия>-win-x64.zip` со страницы **Releases**.
2. Распаковать архив в постоянную папку, например `%LOCALAPPDATA%\Programs\ClaudePets`. Автозапуск хранит полный путь к exe, поэтому папку лучше потом не переносить.
3. Запустить `claude-pets.exe`.

### macOS

Нужна macOS 13 Ventura или новее на Apple Silicon.

1. Скачать `claude-pets-<версия>-macos-arm64.zip` со страницы **Releases** и открыть архив.
2. Перетащить `ClaudePets.app` в папку **Программы** и запускать оттуда. Приложения, оставшиеся в «Загрузках», macOS запускает из временной копии только для чтения, и тогда питомец отказывается ставить хуки и автозапуск.
3. Открыть `ClaudePets.app`.

Если релиз не нотаризован, при первом запуске macOS покажет «Не удалось открыть ClaudePets». Нажать **Готово**, открыть **Системные настройки → Конфиденциальность и безопасность**, нажать **Всё равно открыть** рядом с ClaudePets и подтвердить. Либо один раз выполнить в Терминале:

```bash
xattr -dr com.apple.quarantine /Applications/ClaudePets.app
```

У питомца нет значка в Dock. Когда он спрятан, в строке меню появляется его значок.

Питомец появится в правом нижнем углу основного монитора. При первом запуске программа берёт питомца и размер, выбранные в Codex, если он установлен.

## Питомцы

Питомцы лежат в одной из двух папок:

- `~/.claude/pets/<имя>/` (`%USERPROFILE%\.claude\pets\<имя>\` на Windows);
- `~/.codex/pets/<имя>/` — сюда своих питомцев ставит Codex.

Папка выбирается в контекстном меню питомца: **Папка с питомцами**. По умолчанию используется `.claude/pets`, а если там пусто — `.codex/pets`.

Чтобы перенести питомца из Codex, нужно скопировать его папку из `.codex/pets` в `.claude/pets`.

## Как пользоваться

| Действие | Результат |
|---|---|
| Клик по баблу | Сессия открывается в Claude |
| Навести курсор на стопку | Стопка разворачивается, видно до четырёх баблов; колесо мыши листает остальные |
| Клик по **×** на бабле | Бабл скрывается до следующего хода этой сессии |
| ПКМ по баблу (Control-клик на macOS) | Меню бабла: открыть сессию, скрыть уведомление, не уведомлять об этой сессии |
| Круглая кнопка на краю бабла | Со стрелкой прячет баблы в счётчик у питомца, с числом сворачивает развёрнутую стопку |
| Клик по счётчику у питомца | Баблы возвращаются |
| Клик по питомцу | Окно Claude выходит на передний план |
| Перетащить питомца | Питомец переезжает, позиция запоминается для каждого монитора |
| Отпустить питомца с зажатым Alt (Option на macOS) | Питомец прилипает к углу или середине края экрана |
| ПКМ по питомцу (Control-клик на macOS) | Меню: питомец, размер, папка с питомцами, язык, автозапуск и остальные настройки |
| `Ctrl+Alt+P` (`⌃⌥P` на macOS) | Питомец прячется в трей или строку меню либо возвращается |

Баблы бывают четырёх видов:

| Бабл | Когда появляется |
|---|---|
| Работает, текст мерцает | Идёт ход сессии |
| Ждёт ввода, оранжевый **!** | Claude задал вопрос, ждёт решения по плану или разрешения на инструмент |
| Готово, зелёная галочка | Ход закончился, а сессию ещё не открывали |
| Ошибка, красный **!** | Ход оборвался ошибкой API |

## Точный статус через хуки

Без хуков питомец не видит запрос разрешения на инструмент. Хуки Claude Code сообщают питомцу о таких событиях сразу.

1. Открыть контекстное меню питомца.
2. Выбрать **Точный статус (хуки Claude Code)** и подтвердить установку.

Тот же пункт меню удаляет хуки. Из командной строки:

- Windows: `claude-pets.exe --install-hooks` и `claude-pets.exe --uninstall-hooks`;
- macOS: `/Applications/ClaudePets.app/Contents/MacOS/ClaudePets --install-hooks` и `--uninstall-hooks`.

Хуки добавляются в `~/.claude/settings.json` (`%USERPROFILE%\.claude\settings.json` на Windows). Существующие хуки остаются на месте, перед первой установкой рядом создаётся копия `settings.json.claude-pets.bak`. Если перенести приложение, путь в хуках обновится при следующем запуске питомца.

Если `settings.json` синхронизируется между Windows и Mac, каждый питомец управляет только хуками своей системы, поэтому оба набора уживаются в одном файле. На каждой машине Claude Code не может запустить команду другой системы: такой асинхронный хук просто завершается с ошибкой в фоне и никогда не блокирует Claude.

**Важно:** хуки хранят путь к приложению. Перед удалением программы снять хуки через меню или `--uninstall-hooks`, иначе в настройках Claude Code останутся команды, которые указывают на несуществующий файл.

## Настройки

Настройки лежат в `%APPDATA%\ClaudePets\settings.json` на Windows и в `~/Library/Application Support/ClaudePets/settings.json` на macOS. Почти всё меняется из контекстного меню, вручную полезны эти поля:

| Поле | Значения |
|---|---|
| `hotkey` | Сочетание вида `Ctrl+Alt+P` или `Win+Alt+Space`; на macOS подходят и `Option`, `Cmd`; пустая строка отключает |
| `theme` | `auto`, `light`, `dark` |
| `language` | `auto`, `en`, `ru` |
| `petsFolder` | `auto`, `claude`, `codex` |
| `mascotWidth` | Ширина питомца от 80 до 224 |

Файл нужно править при закрытом питомце: запущенная программа перезаписывает его своими значениями.

## Сборка из исходников

### Windows

Нужна Visual Studio 2022 или Build Tools 2022 с компонентом MSVC x64. CMake и Ninja берутся из поставки Visual Studio.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Готовый файл появится в `build\release\claude-pets.exe`.

- `-Configuration Debug` собирает отладочную версию.
- `-Clean` собирает с нуля.
- `-Version 1.2.3` вшивает версию. Без параметра берётся последний тег `v*`.

### macOS

Нужны Xcode или Xcode Command Line Tools и CMake 3.24 или новее. Если установлен Ninja, сборка использует его.

```bash
brew install cmake ninja
```

```bash
./build.sh
```

Готовое приложение появится в `build/release/ClaudePets.app` и будет подписано ad hoc.

- `--configuration Debug` собирает отладочную версию.
- `--clean` собирает с нуля.
- `--version 1.2.3` вшивает версию. Без параметра берётся последний тег `v*`.
- `--universal` собирает сразу для Apple Silicon и Intel.

## Релизы

Каждое слияние в `dev` публикует релиз сразу с `claude-pets-<версия>-win-x64.zip` и `claude-pets-<версия>-macos-arm64.zip`. Приложение для macOS подписывается Developer ID и нотаризуется, если в репозитории заданы секреты; иначе оно подписано ad hoc:

| Секрет | Значение |
|---|---|
| `MACOS_CERTIFICATE` | Сертификат Developer ID Application с закрытым ключом в виде `.p12` в base64 |
| `MACOS_CERTIFICATE_PASSWORD` | Пароль от `.p12` |
| `MACOS_SIGNING_IDENTITY` | Например, `Developer ID Application: Name (TEAMID)` |
| `APPLE_ID`, `APPLE_TEAM_ID`, `APPLE_APP_PASSWORD` | Apple ID, идентификатор команды и пароль приложения для нотаризации |
