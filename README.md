# Claude Pets — питомец для Claude desktop

Claude Pets показывает на рабочем столе питомца в формате Codex pets и баблы с активными сессиями вкладки **Code** в Claude desktop. Окно без рамки, всегда поверх остальных, прозрачные области пропускают клики к окнам под ним.

Это нативная программа на C++/Win32 с Direct2D: без Electron и рантаймов, один `claude-pets.exe` со статическим CRT. Поведение повторяет Codex Mini: те же анимации, приоритеты баблов, перетаскивание и снап по Alt.

## Что умеет

- Показывает питомца из `~/.codex/pets` или `~/.claude/pets` в формате Codex: `pet.json` и спрайтшит.
- Показывает над питомцем баблы сессий: работает, ждёт ввода, готово, ошибка.
- Открывает сессию в Claude по клику на бабл.
- Переключает анимацию питомца по самому важному баблу.
- Перетаскивается мышью, по Alt примагничивается к одной из шести позиций экрана.
- Поворачивает голову к курсору, если в спрайтшите есть кадры взгляда.
- Прячется в трей по `Ctrl+Alt+P` и возвращается по тому же сочетанию.

## Требования

- Windows 10 или 11, x64.
- Claude desktop с сессиями во вкладке **Code**.
- Хотя бы один питомец в `%USERPROFILE%\.codex\pets\<имя>\` или `%USERPROFILE%\.claude\pets\<имя>\`. Без питомцев рисуется простая оранжевая заглушка.
- Кодек WebP для спрайтшитов `.webp`. Если его нет, при выборе питомца появится сообщение: установить **WebP Image Extensions** из Microsoft Store.

Для сборки дополнительно нужны Visual Studio 2022 или Build Tools 2022 с компонентом MSVC x64. CMake и Ninja берутся из поставки Visual Studio.

## Сборка

1. Открыть PowerShell в корне репозитория.
2. Запустить сборку:

   ```powershell
   powershell -ExecutionPolicy Bypass -File build.ps1
   ```

3. Проверить, что появился `build\release\claude-pets.exe`.

Для отладочной сборки добавить `-Configuration Debug`, для сборки с нуля — `-Clean`.

## Запуск

Запустить `build\release\claude-pets.exe`. Питомец появится в правом нижнем углу основного монитора, при первом показе он поздоровается.

- Повторный запуск не создаёт второй экземпляр, а показывает уже запущенного питомца.
- Флаг `--hidden` запускает питомца сразу спрятанным в трей.
- Пункт **Start with Windows** в контекстном меню добавляет запуск при входе в систему.

При первом запуске программа берёт выбранного питомца и его размер из настроек Codex: `selected-avatar-id` и `avatar-overlay-mascot-width-px` в `~/.codex/config.toml`.

## Управление

| Действие | Результат |
|---|---|
| Навести курсор на стопку баблов | Стопка разворачивается, до четырёх баблов сразу; колесо мыши листает остальные |
| Клик по баблу | Сессия открывается в Claude через `claude://claude.ai/epitaxy/<sessionId>` |
| Клик по **×** на баблe | Бабл скрывается до следующего хода этой сессии |
| ПКМ по баблу | Меню: **Open session**, **Dismiss**, **Mute this session**, **Unmute all sessions** |
| Клик по питомцу | Окно Claude выходит на передний план |
| Перетащить питомца | Питомец переезжает и «бежит» в сторону движения; позиция запоминается для монитора |
| Отпустить питомца с зажатым Alt | Питомец примагничивается к углу или середине края экрана |
| Клик по бейджу у питомца | Скрыть баблы, показать их снова или свернуть развёрнутую стопку |
| ПКМ по питомцу | Контекстное меню |
| `Ctrl+Alt+P` | Спрятать питомца в трей или вернуть его |

В контекстном меню питомца (при русском интерфейсе пункты называются по-русски):

- **Pet** — выбрать питомца.
- **Size** — размер: 80, 112, 160 или 224.
- **Show activity** — показывать баблы.
- **Follow the cursor** — поворачиваться к курсору.
- **Open Claude**, **Open pets folder**.
- **Start with Windows**.
- **Precise status (Claude Code hooks)** — установить или удалить хуки, см. ниже.
- **Language** — системный язык, English или Русский.
- **Hide pet** — спрятать в трей. **Close pet** — завершить программу.

## Статусы баблов

| Бабл | Когда появляется | Анимация питомца |
|---|---|---|
| Работает: текст мерцает, без иконки | Идёт ход сессии; подпись показывает текущее действие: команду, файл, поиск, агента | `running` |
| Ждёт ввода: оранжевый **!** | Claude задал вопрос, ждёт одобрения плана или разрешения на инструмент; либо закончил ход со статусом `blocked` в сводке | `waiting` |
| Готово: зелёная галочка | Ход завершён, а сессию ещё не открывали | `review` |
| Ошибка: красный **!** | Ход оборвался ошибкой API | `failed` |

Главным становится бабл с самым высоким приоритетом: ждёт ввода → ошибка → готово → работает. Внутри одного статуса выше та сессия, где позже было последнее сообщение пользователя.

Баблы исчезают сами: ошибка — через час, ожидание ввода — через сутки, «готово» — через неделю или сразу после просмотра сессии.

Сессия считается просмотренной, если её открыли в Claude, кликнули по баблу или окно Claude было активным с этой сессией около полутора секунд. При первом запуске питомца «готово» показывается только для ходов, завершившихся за последние 15 минут; дальше — для всех ходов, завершившихся после прошлого запуска.

## Откуда берутся сессии и статусы

Программа ничего не меняет в Claude и только читает его данные:

- список сессий, заголовки и время последнего просмотра — `%APPDATA%\Claude\claude-code-sessions\**\local_*.json`; для версии Claude из Microsoft Store тот же каталог лежит в `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude-code-sessions`;
- текущий шаг хода — хвост транскрипта `%USERPROFILE%\.claude\projects\<проект>\<cliSessionId>.jsonl`;
- подпись для «готово» и признак `blocked` — поле `postTurnSummary` в файле сессии, которое Claude заполняет после хода.

Если Claude desktop не запущен, «работает» и ожидание внутри хода не показываются. Баблы завершённых ходов остаются.

## Точный статус через хуки Claude Code

Без хуков питомец не видит запрос разрешения на инструмент: в транскрипте он не отражается. Хуки сообщают питомцу о событиях Claude Code сразу.

Чтобы включить хуки:

1. Открыть контекстное меню питомца.
2. Выбрать **Precise status (Claude Code hooks)** и подтвердить установку.

То же самое из командной строки: `claude-pets.exe --install-hooks`, удаление — `claude-pets.exe --uninstall-hooks`.

Что меняется в `%USERPROFILE%\.claude\settings.json` (или в `settings.json` из `CLAUDE_CONFIG_DIR`):

- в секцию `hooks` добавляется по одной группе на 14 событий: `UserPromptSubmit`, `PreToolUse`, `PostToolUse`, `PostToolUseFailure`, `PermissionRequest`, `PermissionDenied`, `Notification`, `Stop`, `StopFailure`, `SubagentStart`, `SessionStart`, `SessionEnd`, `Elicitation`, `ElicitationResult`;
- каждый хук запускает `claude-pets.exe --claude-pets-hook` напрямую, без оболочки, с `"async": true`, поэтому Claude не ждёт его завершения;
- существующие хуки остаются на месте, перед первой установкой создаётся копия `settings.json.claude-pets.bak`;
- удаление убирает только хуки Claude Pets и возвращает файл в прежний вид.

Хук только передаёт событие запущенному питомцу через `WM_COPYDATA` и завершается. Если питомец не запущен, хук сразу завершается.

**Важно:** хуки хранят полный путь к `claude-pets.exe`. Если перенести exe, при следующем запуске программа сама обновит путь. Перед удалением программы снимите хуки через меню или `--uninstall-hooks`, иначе в настройках Claude Code останутся команды, указывающие на несуществующий файл.

## Настройки

Настройки лежат в `%APPDATA%\ClaudePets\settings.json`. Большинство меняется из контекстного меню; вручную полезны:

| Поле | Значения |
|---|---|
| `hotkey` | Сочетание вида `Ctrl+Alt+P`, `Ctrl+Shift+F9`, `Win+Alt+Space`; пустая строка отключает |
| `theme` | `auto`, `light`, `dark` |
| `language` | `auto`, `en`, `ru` |
| `mascotWidth` | Ширина питомца от 80 до 224 |

Править файл нужно при закрытом питомце: работающая программа перезаписывает его, когда сохраняет позицию и другие изменения.

## Формат питомца

Формат совпадает с Codex pets, поэтому подходят готовые питомцы из `~/.codex/pets`:

- `pet.json` с полями `id`, `displayName`, `description`, `spritesheetPath`, `spriteVersionNumber`;
- спрайтшит из 8 колонок с ячейками 192×208: 1536×1872 (9 рядов, версия 1) или 1536×2288 (11 рядов, версия 2).

| Ряд | Анимация | Кадров |
|---|---|---|
| 0 | `idle` | 6 |
| 1 | `running-right` | 8 |
| 2 | `running-left` | 8 |
| 3 | `waving` | 4 |
| 4 | `jumping` | 5 |
| 5 | `failed` | 8 |
| 6 | `waiting` | 6 |
| 7 | `running` | 6 |
| 8 | `review` | 6 |
| 9–10 | Взгляд в 16 направлениях, только версия 2 | 8 + 8 |

Анимация статуса проигрывается три раза, затем питомец медленно «дышит» в `idle`, как в Codex. При наведении курсора питомец прыгает.

## Диагностика

Команда `claude-pets.exe --diagnose` печатает найденных питомцев, каталоги сессий, статус каждого хода по транскрипту и итоговый список баблов.

Для подробного лога создать пустой файл `%APPDATA%\ClaudePets\debug.log` и перезапустить питомца. В лог пишутся события хуков и смены статусов сессий. Вместо файла можно задать путь в переменной окружения `CLAUDE_PETS_LOG`.

| Симптом | Что проверить |
|---|---|
| Нет баблов, хотя сессия работает | `--diagnose`: есть ли сессия в списке и какой статус у транскрипта. Если сессии нет — проверить, что она открыта во вкладке **Code** Claude desktop |
| Нет бабла «ждёт ввода» при запросе разрешения | Установлены ли хуки: строка `hooks:` в выводе `--diagnose` |
| Вместо питомца оранжевая заглушка | Есть ли каталог питомца с `pet.json` и спрайтшитом; для `.webp` — установлен ли кодек WebP |
| `Ctrl+Alt+P` не работает | Сочетание может быть занято другой программой; задать другое в поле `hotkey` |

## Ограничения

- Показываются только сессии Claude desktop. Сессии Claude Code из терминала в баблы не попадают.
- Ответить в сессию или остановить её из бабла нельзя, как это делает Codex: у Claude desktop нет для этого внешнего интерфейса.
- После выдачи разрешения бабл «ждёт ввода» может оставаться, пока инструмент не завершится: между этими моментами Claude Code не присылает событий.
- Статус «работает» сбрасывается, если 45 минут не было ни записей в транскрипте, ни событий хуков.
- У питомцев версии 1 нет кадров взгляда, пункт **Follow the cursor** на них не влияет.
