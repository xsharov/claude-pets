# Claude Pets

Питомец для Claude desktop на Windows. Он сидит поверх окон и показывает над собой баблы с сессиями вкладки **Code**: какая работает, какая ждёт ответа, какая уже закончила. Клик по баблу открывает сессию в Claude.

Питомцы в формате Codex pets, поэтому подходят готовые из `~/.codex/pets`. Программа — один `claude-pets.exe`, без установщика и рантаймов.

## Что умеет

- Показывает баблы сессий Claude desktop: работает, ждёт ввода, готово, ошибка. У работающей сессии в подписи видно текущее действие: команду, файл или поиск.
- Открывает сессию в Claude по клику на бабл.
- Меняет анимацию питомца по самой важной сессии: работа, ожидание, ошибка, готово.
- Перетаскивается мышью, баблы догоняют его с небольшой инерцией. Если отпустить питомца с зажатым Alt, он прилипнет к углу или середине края экрана.
- Поворачивает голову к курсору, если у питомца есть кадры взгляда.
- Разворачивает стопку баблов при наведении и прячет её в счётчик по кнопке.
- Прячется в трей по `Ctrl+Alt+P`.
- Подстраивается под светлую или тёмную тему Windows. Интерфейс на русском или английском.

## Почему он лёгкий

- Написан на C++20 и Win32 API с Direct2D, без Electron, браузера и .NET. Весь питомец — один exe примерно на 750 КБ, Visual C++ Redistributable не нужен.
- Занимает 20–30 МБ памяти. В покое, пока питомец дышит, а бабл работающей сессии мерцает, тратит около 0,5 % одного ядра.
- Перерисовывает только то, что изменилось: кадр питомца, кнопку или мерцающую строку, а не всё окно.
- Двигается в такт монитору, на котором стоит: на 120 Гц перетаскивание и баблы обновляются 120 раз в секунду, кадр рисуется примерно за миллисекунду.
- Прозрачные места окна не перехватывают клики, поэтому питомец не мешает работать с окнами под ним.
- Держит чёткость на любом масштабе экрана, пиксель-арт увеличивается без размытия.
- В сеть не ходит: читает только локальные файлы Claude, а сессии открывает ссылкой самого Claude desktop.
- Хуки Claude Code запускаются асинхронно и без оболочки, поэтому Claude их не ждёт.
- Проверен на утечки: после 90 циклов скрытия и показа баблов память, хэндлы и GDI-объекты не растут.

## Установка

Нужны Windows 10 или 11 x64 и Claude desktop с сессиями во вкладке **Code**.

1. Скачать `claude-pets-<версия>-win-x64.zip` со страницы **Releases**.
2. Распаковать архив в постоянную папку, например `%LOCALAPPDATA%\Programs\ClaudePets`. Автозапуск хранит полный путь к exe, поэтому папку лучше потом не переносить.
3. Запустить `claude-pets.exe`.

Питомец появится в правом нижнем углу основного монитора. При первом запуске программа берёт питомца и размер, выбранные в Codex, если он установлен.

Windows может предупредить, что файл не подписан. В окне SmartScreen нажать **Подробнее**, затем **Выполнить в любом случае**.

Повторный запуск не открывает второго питомца, а показывает уже запущенного. Флаг `--hidden` запускает питомца сразу в трее.

## Питомцы

Питомцы лежат в одной из двух папок:

- `%USERPROFILE%\.claude\pets\<имя>\`;
- `%USERPROFILE%\.codex\pets\<имя>\` — сюда своих питомцев ставит Codex.

Папка выбирается в контекстном меню питомца: **Папка с питомцами** (в английском интерфейсе **Pets folder**). Рядом с каждой папкой показано, сколько в ней питомцев. По умолчанию используется `.claude\pets`, а если там пусто — `.codex\pets`.

Чтобы перенести питомца из Codex, скопировать его папку из `.codex\pets` в `.claude\pets`.

Питомец — это папка с двумя файлами:

- `pet.json` с полями `id`, `displayName`, `description`, `spritesheetPath`, `spriteVersionNumber`;
- спрайтшит `.webp` или `.png` из 8 колонок с ячейками 192×208: 9 рядов или 11 рядов, если есть кадры взгляда.

| Ряд | Анимация |
|---|---|
| 0 | Покой |
| 1, 2 | Бег вправо и влево, пока питомца тащат |
| 3 | Приветствие |
| 4 | Прыжок при наведении курсора |
| 5 | Ошибка |
| 6 | Ожидание ввода |
| 7 | Работа |
| 8 | Готово |
| 9, 10 | Взгляд в 16 направлениях |

Для `.webp` нужен кодек WebP. Если его нет, программа предложит поставить **WebP Image Extensions** из Microsoft Store. Без питомцев вместо персонажа рисуется оранжевая заглушка.

## Как пользоваться

| Действие | Результат |
|---|---|
| Клик по баблу | Сессия открывается в Claude |
| Навести курсор на стопку | Стопка разворачивается, видно до четырёх баблов; колесо мыши листает остальные |
| Клик по **×** на бабле | Бабл скрывается до следующего хода этой сессии |
| ПКМ по баблу | Меню бабла: открыть сессию, скрыть уведомление, не уведомлять об этой сессии |
| Круглая кнопка на краю бабла | Со стрелкой прячет баблы в счётчик у питомца, с числом сворачивает развёрнутую стопку |
| Клик по счётчику у питомца | Баблы возвращаются |
| Клик по питомцу | Окно Claude выходит на передний план |
| Перетащить питомца | Питомец переезжает, позиция запоминается для каждого монитора |
| Отпустить питомца с зажатым Alt | Питомец прилипает к углу или середине края экрана |
| ПКМ по питомцу | Меню: питомец, размер, папка с питомцами, язык, автозапуск и остальные настройки |
| `Ctrl+Alt+P` | Питомец прячется в трей или возвращается |

Баблы бывают четырёх видов:

| Бабл | Когда появляется |
|---|---|
| Работает, текст мерцает | Идёт ход сессии |
| Ждёт ввода, оранжевый **!** | Claude задал вопрос, ждёт решения по плану или разрешения на инструмент |
| Готово, зелёная галочка | Ход закончился, а сессию ещё не открывали |
| Ошибка, красный **!** | Ход оборвался ошибкой API |

Выше в стопке стоит самый важный бабл: ждёт ввода, потом ошибка, готово и работает. Баблы пропадают сами: ошибка через час, ожидание ввода через сутки, «готово» через неделю или сразу после просмотра сессии.

Программа только читает локальные данные Claude и ничего в нём не меняет. Если Claude desktop закрыт, баблы идущих ходов не показываются, остаются только баблы завершённых.

## Точный статус через хуки

Без хуков питомец не видит запрос разрешения на инструмент. Хуки Claude Code сообщают питомцу о таких событиях сразу.

1. Открыть контекстное меню питомца.
2. Выбрать **Точный статус (хуки Claude Code)** и подтвердить установку.

Тот же пункт меню удаляет хуки. Из командной строки — `claude-pets.exe --install-hooks` и `claude-pets.exe --uninstall-hooks`.

Хуки добавляются в `%USERPROFILE%\.claude\settings.json`. Существующие хуки остаются на месте, перед первой установкой рядом создаётся копия `settings.json.claude-pets.bak`. Если перенести exe, путь в хуках обновится при следующем запуске питомца.

**Важно:** хуки хранят путь к `claude-pets.exe`. Перед удалением программы снять хуки через меню или `--uninstall-hooks`, иначе в настройках Claude Code останутся команды, которые указывают на несуществующий файл.

## Настройки

Настройки лежат в `%APPDATA%\ClaudePets\settings.json`. Почти всё меняется из контекстного меню, вручную полезны эти поля:

| Поле | Значения |
|---|---|
| `hotkey` | Сочетание вида `Ctrl+Alt+P` или `Win+Alt+Space`; пустая строка отключает |
| `theme` | `auto`, `light`, `dark` |
| `language` | `auto`, `en`, `ru` |
| `petsFolder` | `auto`, `claude`, `codex` |
| `mascotWidth` | Ширина питомца от 80 до 224 |

Файл нужно править при закрытом питомце: запущенная программа перезаписывает его своими значениями.

## Сборка из исходников

Нужна Visual Studio 2022 или Build Tools 2022 с компонентом MSVC x64. CMake и Ninja берутся из поставки Visual Studio.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Готовый файл появится в `build\release\claude-pets.exe`.

- `-Configuration Debug` собирает отладочную версию.
- `-Clean` собирает с нуля.
- `-Version 1.2.3` вшивает версию. Без параметра берётся последний тег `v*`.

## Релизы

Каждый MR, влитый в `dev`, выпускает новую версию: CI собирает exe, поднимает версию и публикует релиз с архивом. По умолчанию растёт последняя цифра, например `1.0.0` → `1.0.1`. С меткой `minor` на MR получится `1.1.0`, с меткой `major` — `2.0.0`.

Открытые MR в `dev` CI собирает ещё до слияния. Конкретную версию можно выпустить вручную: **Actions → Release → Run workflow**, поле **version**.

## Если что-то не работает

`claude-pets.exe --diagnose` печатает папки с питомцами, найденные сессии и баблы, которые должны быть на экране. `claude-pets.exe --version` печатает версию.

| Симптом | Что проверить |
|---|---|
| Нет баблов, хотя сессия работает | Есть ли сессия в выводе `--diagnose`. Показываются только сессии из вкладки **Code** Claude desktop, сессии из терминала — нет |
| Нет бабла «ждёт ввода» при запросе разрешения | Установлены ли хуки: строка `hooks:` в выводе `--diagnose` |
| Вместо питомца оранжевая заглушка | Есть ли питомцы в выбранной папке: число видно в меню **Папка с питомцами** |
| `Ctrl+Alt+P` не срабатывает | Сочетание может быть занято другой программой. Задать другое в поле `hotkey` |

Для подробного лога создать пустой файл `%APPDATA%\ClaudePets\debug.log` и перезапустить питомца.

## Ограничения

- Показываются только сессии Claude desktop.
- Ответить в сессию или остановить её из бабла нельзя.
- После выдачи разрешения бабл «ждёт ввода» может держаться, пока инструмент не закончит работу.
